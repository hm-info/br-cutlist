# TT405 / MS300 Kullanım Rehberi

<p class="guide-intro">B&amp;R PLC'li TT405 ve MS300 makineleri aynı kesim listesi (iş dosyası) biçimini ve aynı etiket yazdırma altyapısını kullanır.</p>

<div class="guide-grid">
  <a class="guide-card" href="cut_list_tr.html">
    <span class="guide-card__label">İş dosyaları · TT405 / MS300</span>
    <h2>Kesim listesi</h2>
    <p>16 sütunlu dosya düzeni, makine için gerekli alanlar, montaj, renk / conta ve işlem kodları.</p>
    <span class="guide-card__action">Rehberi aç</span>
  </a>
  <a class="guide-card" href="label_tr.html">
    <span class="guide-card__label">Etiket · TT405 / MS300</span>
    <h2>Etiket ve barkod</h2>
    <p>Yazıcıya giden komutlar, yazı satırları, barkod tasarımlarının içeriği ve etiket simülatörü.</p>
    <span class="guide-card__action">Rehberi aç</span>
  </a>
</div>

<p class="guide-note">Rehberin başındaki PDF indir düğmesiyle bir kopyasını cihazınıza kaydedebilirsiniz.</p>

<p class="guide-note">Kesim listenizi makineye aktarmadan önce <a href="https://hm-info.github.io/csv_file_checker_haffner/">CSV File Checker</a> uygulamasında <strong>TT405-B&amp;R</strong> seçeneğiyle kontrol edebilirsiniz.</p>
